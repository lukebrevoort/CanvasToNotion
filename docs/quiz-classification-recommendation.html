Patch recommendation

Classify quizzes from Canvas signals,
not from names.

Prepared after tracing CS 334 “Syllabus Quiz” through live Canvas, SQLite, and Notion.

Observed

New Quiz over LTI

is_quiz_lti_assignment=true, while quiz_id=null and submission type is external_tool.

Bug

One-signal classifier

The sync only checked quiz_id, so New Quizzes projected to Notion with Quiz=false.

Decision

Explicit signals only

Combine Canvas quiz flags and online_quiz; never guess from the assignment title.

Recommended classification

Return true when any explicit Canvas signal is present:

  • quiz_id != null for classic quizzes
  • is_quiz_assignment === true
  • is_quiz_lti_assignment === true for New Quizzes launched through LTI
  • submission_types contains online_quiz
